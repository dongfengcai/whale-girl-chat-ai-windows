# 鲸鱼娘聊天AI · Windows 版

在 **Windows 电脑上跑一个会像真人一样聊天的 QQ 机器人**，不需要 Linux 服务器，
不需要 Docker，不需要管理员权限，不需要你懂命令行。

双击 `安装.cmd` → 双击 `启动.cmd` → 微信…不对，QQ 扫码 → 完事。

> 这是 [鲸鱼娘聊天AI](https://github.com/dongfengcai/whale-girl-chat-ai) 的 Windows 版本。
> 原来的版本跑在 Linux 服务器上（Docker），这个是给「自己电脑挂着」和「Windows 服务器」用的。

**两个版本怎么选？**

| 你的情况 | 用哪个 |
|---|---|
| 有台云服务器，想 7×24 挂着不掉线 | [Linux 版](https://github.com/dongfengcai/whale-girl-chat-ai) |
| 想在自己电脑上跑，不想碰命令行、不想装 Docker | **就是这个 Windows 版** |
| Windows 服务器，常年开机 | 也是这个 |

## 怎么拿到这个包

**方式一：直接下载（不想碰命令行就用这个）**

页面右上角绿色的 **`Code`** 按钮 → **`Download ZIP`**，
或者去 **Releases** 页面下载打包好的 `whale-girl-chat-ai-windows.zip`。

下载完解压到**任意一个你自己找得到的位置**。

> 解压路径里可以有中文和空格（比如 `D:\下载\鲸鱼娘`），脚本都处理过了。
> 但**别放在 `C:\Program Files` 下面** —— 那里写文件要管理员权限，会失败。

**方式二：git clone**（想跟着改代码的）

```cmd
git clone https://github.com/dongfengcai/whale-girl-chat-ai-windows.git
```

**拿到之后先确认一下完整性**

解压出来的文件夹里应该**至少有这 6 个 .cmd**：

```
安装.cmd      启动.cmd      停止.cmd
状态.cmd      配置对接.cmd   设置人设.cmd
```

6 个都在就说明下载完整了，可以开始看下一节。
少文件的话重新下载 —— 大概率是解压中断了。

## 它和 Linux 版有什么不一样

|  | Linux 版（原版） | Windows 版（这个） |
|---|---|---|
| QQ 协议端 | NapCat 跑在 Docker 里 | NapCat 直接跑，用你电脑上装的 QQ |
| 机器人本体 | AstrBot 跑在 Docker 里 | AstrBot 直接跑，用自带的便携版 Python |
| 需要装什么 | Docker、docker compose | **什么都不用装** |
| 管理面板 | 要开 SSH 隧道才能访问 | 直接开 http://127.0.0.1:6185 |
| 内存占用 | 两个容器约 900 MB | 差不多，NapCat 自带完整 QQ |
| 适合 | 云服务器 7×24 挂机 | 自己的电脑 / Windows 服务器 |

**共同点**：6 个插件、人设文件、行为逻辑完全一样，两边可以随时互相搬。

## 开始之前

**需要的东西**

- Windows 10 或 11，64 位
- 约 **3 GB** 磁盘空间（依赖包比较大）
- 一个 **QQ 号**
- 一个 **DeepSeek API Key**（可以不填，但余额熔断和表情自动打标签要用）
  - 获取地址：https://platform.deepseek.com/api_keys

**两个提醒**

> ⚠️ **强烈建议用小号。** NapCat 走的是非官方协议，有封号风险。
> 主号被封了你找不回来。

> ⚠️ **电脑关机机器人就下线。** 想 7×24 挂着的话，用云服务器版更合适；
> 或者用 Windows 服务器 / 一台常年不关的电脑。

**第一次运行会被 Windows 拦一下**

因为这是从网上下载的压缩包，Windows 会给里面的脚本打上「来自 Internet」的标记。
双击 `安装.cmd` 时可能弹出蓝色的 **「Windows 已保护你的电脑」**：

> 点 **「更多信息」** → **「仍要运行」**。

这是 SmartScreen 对所有未签名脚本的标准反应，不是这个脚本有问题。
来源你自己清楚就行 —— 不放心可以先通读 `install.ps1`，它没有加密也没有编译过。

如果双击后窗口一闪而过，右键 `安装.cmd` → **以管理员身份运行** 试试
（其实不需要管理员权限，只是这样更容易留住窗口看报错）。

## 三步走

### 第一步：安装

双击 **`安装.cmd`**。

会依次问你三件事（都可以直接回车跳过）：

1. **DeepSeek API Key** —— 留空也行，之后能在面板里补
2. **你的 QQ 号** —— 管理员，用来收余额告警、管理表情库
3. **允许收集表情的群号** —— 留空表示所有群都收

然后它会自动下载并配置：

```
  [OK] 插件包完整：6 个插件
  ==> Python 3.12.10（便携版）
  ==> AstrBot v4.28.1
  ==> Python 依赖            <- 最慢的一步，1.5 GB 左右
  ==> 安装插件
  ==> AstrBot 主配置
  ==> 插件配置
  ==> NapCat v4.18.28
```

**这一步视网速要 10-40 分钟**，主要时间花在装依赖上。
中途关掉窗口也没事，重新运行会从断的地方接着装。

装完会在桌面放一个「启动鲸鱼娘聊天AI」的快捷方式。

### 第二步：启动 + 登录 QQ

双击 **`启动.cmd`**。

窗口里会打印出你要的东西，**先记下来**：

```
  管理面板    http://127.0.0.1:6185
  用户名      astrbot
  初始密码    xxxxxxxx

  QQ 登录     http://127.0.0.1:6099/webui
  登录密钥    xxxxxxxx
```

（没看到的话，双击 `状态.cmd` 也能再查一次。）

然后：

1. 浏览器打开 **http://127.0.0.1:6099/webui**
2. 填上面那个**登录密钥**
3. 用手机 QQ **扫码登录**

> 扫码时 NapCat 那个最小化的黑窗口会显示二维码，看不到就点开它。

### 第三步：开起来

双击 **`配置对接.cmd`** —— 把 NapCat 接到 AstrBot 上（会自动填好地址和 token）。

再双击 **`设置人设.cmd`** —— 把鲸鱼娘的人设写进去。

最后双击 **`停止.cmd`**，再双击 **`启动.cmd`**（配置要重启才生效）。

然后打开 **http://127.0.0.1:6185**，用 `astrbot` + 初始密码登录，
**第一件事是改密码**。最后私聊机器人发个「你好」试试。

> 如果没反应，双击 `状态.cmd`，把输出发出来基本就能定位问题。

## 目录里都是什么

**你只需要的 6 个：**

| 文件 | 干什么 |
|---|---|
| `安装.cmd` | 装。/ 装坏了重新跑一次也行 |
| `启动.cmd` | 启动 AstrBot + NapCat |
| `停止.cmd` | 全部关掉 |
| `状态.cmd` | 进程、端口、日志、插件加载情况 —— **出问题先跑这个** |
| `配置对接.cmd` | 登录 QQ 之后跑一次，把 NapCat 接到 AstrBot |
| `设置人设.cmd` | 把鲸鱼娘人设写进数据库（启动过一次之后再跑） |

**其余的东西**（别乱删）：

| 路径 | 是什么 |
|---|---|
| `persona-whale-girl.md` | 人设。**想改性格就改这个文件，然后重跑 `设置人设.cmd`** |
| `plugins\` | 6 个插件源码（安装时会拷进 AstrBot） |
| `config.env` | 你填的 API Key / QQ 号，安装时生成 |
| `runtime\` | 便携版 Python（约 45 MB） |
| `app\AstrBot\` | 机器人本体 |
| `app\AstrBot\data\plugins\` | 实际生效的插件 |
| `app\AstrBot\data\config\` | 插件配置（也能在面板里改） |
| `app\AstrBot\data\data_v4.db` | 人设、会话记录都在这（SQLite） |
| `napcat\` | QQ 协议端 |
| `logs\` | 日志。`astrbot.log` 和 `napcat.log` |
| `run\` | 内部用的小文件（token 之类） |

**6 个插件分别干什么：**

| 插件 | 作用 |
|---|---|
| `astrbot_plugin_balance_guard` | 余额红线熔断 + 每群每日 token 限额 |
| `astrbot_plugin_identity` | 让 AI 知道「谁在说话、什么身份」 |
| `astrbot_plugin_media_pacer` | 图片识别限流，不影响文字对话 |
| `astrbot_plugin_meme` | 发表情包，自动收集群里的表情 |
| `astrbot_plugin_poke_react` | 把「戳一戳」当成 @ |
| `astrbot_plugin_reply_arbiter` | 多人同时 @ 时，优先回正在聊的那个 |

## 常见问题

### ⚠️ 启动失败，提示端口被占用

最常见的原因：**你之前用 SSH 隧道连服务器上的面板，隧道还开着。**
隧道会占着本机的 6099 和 6185 端口，Windows 版就抢不到了。

`启动.cmd` 会直接告诉你占用者是谁。看到是 `ssh` 就：

```cmd
taskkill /PID <它显示的PID> /F
```

或者直接把那个 tunnel 窗口关掉。

### 下载失败 / 卡住不动

**浏览器能打开网页，但脚本下载失败** —— 这是最典型的情况：
git、curl、PowerShell 都**不会自动使用 Windows 的「系统代理」**，但浏览器会。

脚本已经会自动读系统代理了（安装时会打印一行 `检测到系统代理：...`）。
如果还是失败，在 `config.env` 里手动加一行，端口换成你自己客户端里的：

```
PROXY=http://127.0.0.1:7897
```

常见端口：Clash Verge 是 `7897`，Clash for Windows 是 `7890`，v2rayN 是 `10809`。

### 依赖装不上

八成是网络。手动重试（把路径换成你解压的位置）：

```powershell
cd app\AstrBot
..\..\runtime\python\tools\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 面板打开是 404

缺管理面板文件。重新跑一次 `安装.cmd`，它会补下载。
还不行就手动：去 [AstrBot Releases](https://github.com/AstrBotDevs/AstrBot/releases) 下载
`AstrBot-v4.28.1-dashboard.zip`，解压出 `dist` 文件夹，放到 `app\AstrBot\data\` 下面。

### 插件没生效

看 `状态.cmd` 的输出。AstrBot **只在启动时扫描插件目录**，面板里的「重载插件」不够，
必须 `停止.cmd` → `启动.cmd`。

### QQ 掉线了

NapCat 掉线不会自动恢复，得重新扫码：打开 http://127.0.0.1:6099/webui 再扫一次。

登录状态存在 `napcat\` 里面，正常的话重启电脑也不用重新扫。

### 内存占用太高

NapCat 跑着完整的 QQ 客户端，比较吃内存。看看 `状态.cmd` 的内存数字，
如果长期超过 1 GB，可以在 AstrBot 面板里减少消息处理量，或者少加几个群。

### 想改人设

改 `persona-whale-girl.md`（里面写了怎么调），然后重跑 `设置人设.cmd`，再重启。

## 开机自启

不想每次开机手动点，两种办法：

**办法一：任务计划程序（推荐）**

1. Win+R 输入 `taskschd.msc` 回车
2. 右侧「创建任务」
3. **常规**：勾「不管用户是否登录都要运行」和「使用最高权限运行」
4. **触发器**：新建 → 开始任务选「启动时」
5. **操作**：新建 → 程序或脚本填 `启动.cmd` 的完整路径，
   「起始于」填这个文件夹的路径
6. 确定

**办法二：启动文件夹（简单，但要登录后才启动）**

Win+R 输入 `shell:startup` 回车，把 `启动.cmd` 的快捷方式拖进去。

## 卸载

1. 双击 `停止.cmd`
2. 把整个文件夹删掉
3. 桌面上的「启动鲸鱼娘聊天AI」快捷方式删掉

就这些 —— 它不写注册表，不装服务，不往系统目录丢东西。
（如果你建过开机自启的任务，记得去任务计划程序里删掉。）

## 安全提醒

- **用 QQ 小号。** 非官方协议端有封号风险，这是所有 NapCat 类方案的共同问题。
- **面板密码立刻改。** 三个端口都只绑本机，但同一台电脑上的其他程序能访问。
- **别把 6185 / 6099 暴露到公网。** 想远程访问就用 SSH 隧道或者内网穿透 + 密码。
- **`config.env` 里有你的 API Key**，别把这个文件夹传给别人。
